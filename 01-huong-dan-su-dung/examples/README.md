## Nếu làm sai thì sao (❌ SAI / ✅ ĐÚNG)

**❌ SAI — copy file `.sh` về chạy luôn trong repo thật.** *Vì sao?* Mẫu dùng tên branch/org giả, có script tạo/xoá file để minh hoạ — chạy thẳng là dính việc thật.

**✅ ĐÚNG — đọc 10 dòng đầu mỗi file** (ai cũng ghi mục đích + biến cần đổi), chạy thử trên nhánh tạm hoặc repo playground rồi hãy dùng thật.

**Bài học:** examples là *bản in* để cắt — không phải lệnh đã đo may.
