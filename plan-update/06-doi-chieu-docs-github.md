## Kết luận: Top 10 khẳng định kiểu tutorial phổ biến mà docs GitHub KHÔNG hỗ trợ

1. **"Copilot Extensions (GitHub App) còn dùng được / là đường mở rộng chính"** — retired 10/11/2025; docs hiện hành không còn tính năng này. ([changelog](https://github.blog/changelog/2025-09-24-deprecate-github-copilot-extensions-github-apps/))
2. **"AHP/Agent Host là protocol của GitHub Copilot (docs GitHub)"** — docs GitHub **không** document AHP; đó là VS Code/Microsoft. Docs GitHub chỉ có **ACP** (`--acp`, public preview) cho CLI.
3. **"Hooks chỉ chạy Local / cloud agent không chạy hooks"** — docs hooks-reference xác nhận hooks chạy ở **cả Copilot in the cloud** (sandbox ephemeral, subset events, `.github/hooks/*.json` only).
4. **"prompt files `.prompt.md` đã deprecated"** — docs GitHub **không** dùng từ deprecated; chỉ mô tả tính năng hiện hành. Giới hạn "Local harness" + migrate là **VS Code docs**.
5. **"instruction enforcement" (policy ép model tuân instructions)** — không tồn tại trong docs; docs định vị instructions là context, "do not guarantee" compliance. Enforcement thật = hooks/managed settings/policy hooks/content exclusion.
6. **"Premium requests + multiplier ×13 là đơn vị billing hiện hành"** — legacy từ 01/06/2026; hiện hành **GitHub AI Credits** per-token, code review theo **effort level Lite/Balanced/Max** (không multiplier 13x). "Premium session" chưa từng là thuật ngữ docs.
7. **"Content exclusion không áp dụng cho sandbox/cloud agent"** — docs đánh dấu ✓ content exclusion cho Copilot in the cloud (bao gồm cloud sandboxes) và code review; chỉ giới hạn ở chỗ "not a security boundary, không đảm bảo với third-party MCP/symlink/indirect access".
8. **"`plugin.json` khai `agents/skills/hooks/mcpServers` là format chuẩn"** — chỉ **legacy format**; **Agent Plugins 1.0** là schema **đóng**: components portable = `skills/` + root `mcp.json`; phần Copilot-specific phải vào `com.github.copilot/`; schema không nhận là sẽ **reject cả plugin**.
9. **"org instructions cá nhân qua file `~/.copilot/org-customizations/copilot-instructions.md`" và "`~/.claude/skills` là path cá nhân được CLI đọc"** — docs GitHub: personal/org instructions GitHub.com làm **qua UI**; personal skills = `~/.copilot/skills`/`~/.agents/skills`; `~/.claude/skills` (user-level) không xuất hiện trong load-order docs nêu.
10. **"`--max-ai-credits` = cap cả phiên; CLI GA 03/2026; audit retention 180 ngày; auto-select −10%"** — docs mô tả `--max-ai-credits` là **soft cap cho lượt tiếp theo** (cap cả phiên là `--max-session-credits`), và **không có** ngày GA CLI / con số 180 ngày riêng Copilot / discount 10% trong các trang đã đối chiếu.
